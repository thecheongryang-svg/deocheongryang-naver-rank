# 네이버 플레이스 순위 대시보드

"더청량"이 네이버 플레이스에서 키워드별로 몇 위인지(광고 제외) 추적하는 도구. 매일 자동으로 기록되고, 대시보드에서 추이와 경쟁사 비교까지 한눈에 봅니다.

## 대시보드 열기

`대시보드_실행.bat` 더블클릭 → 브라우저가 자동으로 열립니다 (http://localhost:8765).
끌 때는 뜬 검은 창을 닫으면 됩니다. 창을 닫아도 매일 자동 기록 자체는 계속됩니다(아래 참고).

대시보드에서:
- 키워드별 현재 순위 + 전일 대비 변화
- 일별 순위 추이 그래프
- "지금 전체 새로고침" 버튼으로 즉시 재확인
- 경쟁사 비교表(리뷰 수·사진 수·거리) + 순위 영향 요소 분석

## 매일 자동 기록

Windows 작업 스케줄러에 `더청량_네이버순위_일일체크`라는 이름으로 등록돼 있어서, **매일 오전 9시**에 자동으로 `keywords.txt`의 키워드를 전부 체크해서 `순위기록.csv`에 쌓습니다. 컴퓨터가 꺼져 있던 날은 건너뜁니다.

확인/수정하려면:
- 작업 스케줄러 앱에서 "더청량_네이버순위_일일체크" 검색
- 삭제하려면: `schtasks /delete /tn "더청량_네이버순위_일일체크" /f`
- 실행 시간을 바꾸려면: 작업 스케줄러에서 트리거 수정, 또는 다시 `schtasks /create ... /st 원하는시각` 로 덮어쓰기

## 체크 키워드 추가/삭제

`keywords.txt`를 메모장으로 열어서 한 줄에 하나씩 수정하면 됩니다. 다음 자동 실행(또는 대시보드 새로고침)부터 바로 반영됩니다.

## 수동으로 터미널에서 체크하고 싶을 때

```
cd "C:\Users\minni\Desktop\더청량-마케팅\네이버순위체크"
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `rank_core.py` | 네이버 API 호출 등 공통 로직 |
| `naver_place_rank.py` | 수동 CLI 체크 |
| `daily_check.py` | 매일 자동 실행되는 스크립트 (작업 스케줄러가 호출) |
| `server.py` | 대시보드 로컬 서버 |
| `dashboard.html` | 대시보드 화면 |
| `keywords.txt` | 추적할 키워드 목록 (편집 가능) |
| `순위기록.csv` | 쌓이는 기록 (엑셀로도 열림) |
| `competitor_snapshot.json` | 경쟁사 분석용 스냅샷 데이터 |

## 작동 원리 / 한계

네이버 지도 앱이 "업체 목록" 탭에서 실제로 호출하는 내부 API(`api.place.naver.com/graphql`)를 그대로 호출합니다. 공식 공개 API가 아니라서 네이버가 내부 구조를 바꾸면 깨질 수 있습니다 — 그럴 땐 다시 손봐드릴게요.

기본적으로 더청량 위치(청량리) 좌표를 검색 기준점으로 씁니다. 네이버는 조회 위치에 따라 결과가 달라질 수 있어서, 완전히 동일한 조건으로 비교하려면 항상 같은 기준점을 쓰는 게 중요합니다 — 이미 그렇게 고정해뒀습니다.
